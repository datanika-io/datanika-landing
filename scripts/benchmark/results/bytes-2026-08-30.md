## Caveat

The post-normalization figure is what dlt writes to disk for **this**
destination and loader file format. A different destination (Parquet-based, or
a warehouse with a different staging format) produces a different byte count
for the same rows. Cite it as *this pipeline, this destination* -- never as a
universal bytes-per-row constant.
